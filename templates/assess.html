Assess an archive

What remediating a set of PDFs would take, read off the files themselves. Nothing is ingested: no article is created, no database row is written, and the uploads are deleted when this page finishes rendering. Use it on an archive before deciding whether to take it in.

One file or many; up to {{ shape.max_files }} a pass, and {{ shape.max_mb }} MB in total. A whole back catalogue at once is the command line: python assess.py <folder>, which has no cap and can also read a folder of HTML.

Reads every page a second time, so it roughly doubles how long a file takes.

{% if shape.validate_ready %} A file saying it conforms and a checker agreeing are two different facts. verapdf is a JVM process at about thirteen seconds a file, so this pass takes at most {{ shape.max_validate_files }} files. {% else %} verapdf is not on PATH, so no verdict can be taken. What the files declare about themselves is still read. Install it from verapdf.org. {% endif %}
